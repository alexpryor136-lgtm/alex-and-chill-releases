# Alex & Chill for Fire TV

Finished app builds only. Each Fire TV checks this page for updates and offers them in the app.

## First install

1. On the Fire TV: **Settings → My Fire TV → Developer Options → Install unknown apps**, and turn on **Downloader**.
2. Install the **Downloader** app from the Amazon Appstore and open it.
3. Enter this address and choose **Go**:

   `https://github.com/alexpryor136-lgtm/alex-and-chill-releases/releases/latest/download/alex-and-chill.apk`

4. Choose **Install**, then **Open**, and sign in with your username and password.

After that, updates arrive inside the app. The first time, it asks you to allow **Alex & Chill** to install apps.
